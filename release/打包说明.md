# 高清动画包（webm-1280）

## 为什么单独放

106 个动画合计 **425MB**，直接塞进 Git 仓库会让 clone 变得很慢。
建议放到 **GitHub Release**，仓库里只放说明。

## 怎么打包

```bash
cd ~/.dsh/profiles/desktop/node_modules/dsh-pet/assets
zip -r webm-1280.zip webm -x "*.bak*"
```

## 怎么装

1. 下载 `webm-1280.zip`
2. 解压得到 `webm/`
3. 覆盖到：
   ```
   ~/.dsh/profiles/desktop/node_modules/dsh-pet/assets/webm/
   ```
4. 重启 DSH

## 校验

每个视频应为 **1280×720**，带 alpha：

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0 待机呼吸休闲.webm
# 1280,720
```

抽一帧看透明：

```bash
ffmpeg -c:v libvpx-vp9 -i 待机呼吸休闲.webm -frames:v 1 check.png
```

用图片查看器打开，背景应是透明的（不是黑底）。

## 注意

- 必须用 `-c:v libvpx-vp9` 解码，否则 alpha 会丢，显示成黑方块
- 原版备份在 `assets/webm.bak-upscale/`，可随时回滚
